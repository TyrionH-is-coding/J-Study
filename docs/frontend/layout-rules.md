# J-Study 前端布局与信息架构规则

## 文档状态

本文件是 J-Study 当前正式的前端页面范围、信息架构和响应式布局基线。

- 状态：已通过初稿审阅，待按实施计划落地。
- 适用范围：正式前端 `apps/web/**`。
- 视觉状态：未冻结。颜色、字体、圆角、图标和手绘元素不属于本文件的强制规则。
- 参考稿：`.superpowers/brainstorm/frontend-auth-20260731-190327/content/all-pages-layout-draft-05.html`。

当本文件与较早的 `clinical-workbench-spec.md` 在页面范围、布局或视觉方向上冲突时，以本文件为准。后端 API 合同、数据结构和安全限制仍以后端代码及架构文档为准。

## 设计目标

J-Study 前端首先是学习任务工作区，不是营销网站或通用仪表盘。

布局必须做到：

1. 用户能快速判断当前处于选择模式、提交材料、任务处理还是阅读资料阶段。
2. 输入材料、生成状态、学习正文和来源证据保持清晰分区。
3. 不展示后端尚未支持的按钮、页面或工作流。
4. 桌面端充分利用宽屏，移动端不通过缩小桌面布局来勉强适配。
5. 页面结构可以在正式视觉规范确定后换肤，而不需要重做路由和功能模块。

## 权威边界

前端设计与实现按以下顺序判断事实：

1. 后端公开 API、响应结构和运行状态。
2. `docs/product/` 中的产品定义。
3. 本文件规定的页面、模块和布局。
4. `.superpowers/brainstorm/` 中的视觉初稿。

视觉初稿用于说明结构，不是生产代码，也不是精确像素稿。

## 页面范围

当前需要设计和实现八个主要页面或主要页面状态。

| 编号 | 页面或状态 | 主要任务 |
|---|---|---|
| 01 | 登录 | 建立用户会话 |
| 02 | 注册 | 使用邀请码创建账号 |
| 03 | 模式选择 | 选择本次资料处理方式 |
| 04 | 单课件提交 | 提交一份 PDF 和可选大纲 |
| 05 | 课程大纲提交 | 提交必需大纲和多份有序 PDF |
| 06 | 任务状态 | 展示排队、处理、完成或失败 |
| 07 | 学习资料阅读器 | 阅读生成内容并核对来源 |
| 08 | 管理后台 | 管理运行配置、诊断与邀请码 |

以下能力不建立独立页面：

- 账号信息和退出登录：放入学生顶栏账号菜单。
- 来源、证据和 PDF：放入阅读器来源面板。
- Manifest、Learning Map、Coverage、Trace：放入阅读器检查器抽屉。
- Health、Readiness 和诊断信息：放入管理后台。
- Batch Courseware：仅在模式选择页显示禁用入口。

当前不设计：

- 任务历史页，因为后端没有用户任务列表接口。
- 用户管理页，因为后端没有用户管理合同。
- 任务取消和原任务重试操作，因为后端没有相应接口。
- 解析器选择界面，因为解析配置由管理员负责。
- 解析后大纲编排确认页，因为后端没有独立预解析和编排接口。

## 路由原则

当前学生端路由保持精简：

```text
/                         根据认证状态跳转
/login                    登录
/register                 注册
/modes                    模式选择
/modes/single-courseware  单课件提交
/modes/course-outline     课程大纲提交
/jobs/[jobId]             任务状态与完成后的阅读工作区
```

管理后台：

```text
/admin/settings           管理设置与诊断
```

`/jobs/[jobId]` 负责一个任务的完整生命周期：

- 处理中显示任务状态布局。
- 失败或取消显示安全错误状态。
- 完成后切换到学习资料阅读器。

除非后续产品需求明确要求深链接，否则不额外增加仅用于区分“任务状态”和“阅读器”的路由。

## 三种页面壳层

### 认证壳层

适用于登录和注册。

- 不显示学生工作台导航。
- 页面中心为单栏认证表单。
- Logo、标题、说明、表单和页面切换入口保持同一垂直轴线。
- 服务端错误显示在表单内部，不只使用短暂 Toast。
- 不提供社交登录或“忘记密码”，除非后端先提供对应合同。

### 学生工作台壳层

适用于模式选择、两个提交页、任务状态和阅读器。

顶栏至少包含：

- J-Study 品牌入口。
- 当前层级或任务上下文。
- 账号菜单。

模式选择可以使用完整内容宽度。提交页、任务页和阅读器根据任务特征采用不同工作区网格，不强制套用同一侧边栏。

### 管理后台壳层

管理后台与学生工作台分开。

- 顶栏放置全局状态、重新加载和保存操作。
- 左侧导航用于切换设置分区。
- 中间为当前分区表单。
- 宽屏右侧显示运行状态或未保存变更摘要。
- 管理员密钥始终遮罩显示。

## 全局布局规则

### 信息层级

每个页面按以下顺序组织：

1. 当前页面或任务名称。
2. 一句说明当前要做什么。
3. 主要工作区。
4. 与主要任务直接相关的状态、错误和操作。

不使用大型营销 Hero、统计大盘或与当前任务无关的内容填充首页。

### 容器和卡片

- 使用网格、留白和分隔线建立主要层级。
- 不用多层嵌套卡片表示普通页面分区。
- 卡片只用于重复项目、模态内容、工具面板和需要边界的摘要。
- 页面主操作在一个视口内只保留一个最高优先级。

### 状态与错误

- 表单校验错误紧邻对应字段或上传区。
- Readiness 异常必须解释原因并禁用提交。
- 任务失败只显示后端提供的安全错误。
- 401 状态回到登录，并保留允许恢复的目标地址。
- 弱证据章节仍可阅读，但必须与充分证据状态区分。
- 不依赖颜色作为唯一状态提示，状态同时使用文字或图标。

### 身份与位置

- 来源身份使用 `source_id`，文件名只用于显示。
- 学习位置与 PDF 查看位置分别管理。
- 点击引用只改变右侧来源预览，不改变正文阅读位置。

## 逐页布局规则

### 01 登录

模块：

- Logo 与产品名。
- 邮箱。
- 密码。
- 服务端错误区域。
- 登录按钮及加载、禁用状态。
- 注册入口。

布局：

- 使用居中的单栏表单。
- 移动端保持同一信息顺序，不增加额外装饰区。

### 02 注册

模块：

- Logo 与产品名。
- 邮箱。
- 密码。
- 确认密码。
- 邀请码。
- 客户端校验和服务端错误。
- 创建账号按钮。
- 登录入口。

确认密码只用于客户端一致性校验，不改变后端注册合同。

### 03 模式选择

模块：

- 学生顶栏。
- 页面标题与简短说明。
- 模式对比列表。
- 每个模式的输入、输出、适用场景和可用状态。
- 进入模式的操作。

模式顺序：

1. 课程大纲：主要模式。
2. 单课件：可用模式。
3. 批量课件：禁用并标记暂未开放。

使用纵向对比行，不使用三个内容相近的大型营销卡片。

### 04 单课件提交

桌面端使用三段式布局：

```text
左：步骤栏
中：上传和表单
右：提交摘要与生成操作
```

模块：

- 必需的单个 PDF。
- 可选的大纲文件。
- 文件格式和大小校验。
- 文件移除或替换。
- 模式、文件数量和服务状态摘要。
- 生成学习资料按钮。

不暴露 `parser_profile_id`。只有在后端返回多个公开场景时才显示 `scenario_id` 选择。

### 05 课程大纲提交

沿用三段式提交布局。

模块：

- 必需的大纲文件，支持后端允许的格式。
- 一份或多份 PDF。
- PDF 有序列表。
- 提交前的客户端排序。
- 文件校验、移除和替换。
- 文件数量、总大小和服务状态摘要。
- 生成课程学习资料按钮。

PDF 列表顺序必须与 multipart 中重复 `pdfs` 字段的提交顺序一致。

### 06 任务状态

模块：

- 任务名称和标识。
- 总体进度百分比。
- 阶段时间线：排队、解析、检索、生成、打包。
- 尝试次数。
- 输入材料摘要。
- 失败或取消的安全错误。
- 返回模式选择和新建任务。

完成后进入同一任务的阅读工作区。没有后端接口时，不显示取消或重试按钮。

### 07 学习资料阅读器

桌面端使用三栏：

```text
左：章节目录和来源列表
中：生成的学习资料
右：来源上下文和 PDF 页面预览
```

顶栏模块：

- 返回入口。
- 资料标题、模式和完成状态。
- 质量状态。
- 导出。
- 检查器入口。

左栏：

- 章节顺序。
- 当前章节。
- `generated`、`weak_evidence` 和 `failed` 状态。
- 课件来源切换。

中栏：

- 标题、段落、列表、表格、提示、公式等材料块。
- 行内引用。
- 章节质量和引用覆盖信息。

右栏：

- `source_id` 对应的来源选择。
- 当前引用上下文。
- PDF 页码导航。
- 页面图像预览。

Manifest、Learning Map、Coverage、Trace 和更完整的质量信息放入检查器抽屉，不拆成新的主页面。

### 08 管理后台

左侧分区：

1. 总览与诊断。
2. 模型与检索。
3. 文档解析。
4. 内容与场景。
5. 知识片段。
6. 邀请码。

中间表单根据分区切换。宽屏右侧可以显示：

- API 和依赖服务状态。
- 当前配置是否可用。
- 未保存变更摘要。
- 与当前分区直接相关的测试结果。

邀请码区域同时展示邀请码和使用记录。知识片段允许编辑后端已支持的 JSON 内容，但必须提供格式校验。

## 响应式规则

验收视口：

```text
390x844
768x1024
1440x900
```

### 桌面端：宽度不小于 1200px

- 提交页显示步骤、表单和摘要三栏。
- 阅读器显示目录、正文和来源三栏。
- 管理后台显示导航、表单和状态三栏。

### 平板端：768px 至 1199px

- 提交页保留步骤和表单，摘要下置。
- 阅读器保留正文和来源，目录进入抽屉。
- 管理后台保留导航和表单，状态进入抽屉。

### 手机端：小于 768px

- 页面采用单列。
- 提交步骤改为横向概要。
- 主要提交操作可以固定在底部，但不能遮挡错误信息。
- 阅读器使用“目录 / 正文 / 来源”三个分段入口。
- 管理分区使用可横向滚动的顶部导航。

所有主要页面必须满足：

```text
document.documentElement.clientWidth === document.documentElement.scrollWidth
```

## 视觉方向边界

已经确认：

- 中文为主。
- 布局简洁、克制。
- Logo 使用用户提供的手绘 J 方向。
- 登录和注册可参考 shadcn/ui 的 `login-04`、`signup-04` 结构，但不照搬其双栏图片区域。

尚未冻结：

- 最终色板。
- 字体组合。
- 圆角、阴影和边框细节。
- xkcd 手绘程度。
- 火柴人漫画、彩蛋和幽默文案。

线框稿中的黑白灰只用于辨识结构。实现布局时不得把线框颜色当作最终品牌规范，也不得自行加入漫画或冷笑话。

## 技术与组件边界

继续使用：

- Next.js App Router。
- TypeScript。
- Tailwind CSS。
- shadcn/ui 基础组件。
- TanStack Query。

模块职责：

```text
apps/web/src/features/auth
apps/web/src/features/modes
apps/web/src/features/single-courseware
apps/web/src/features/course-outline
apps/web/src/features/job
apps/web/src/features/reader
apps/web/src/features/source-preview
apps/web/src/features/admin
apps/web/src/lib/api
apps/web/src/components/ui
```

- `components/ui` 不包含 J-Study 业务状态。
- `lib/api` 不包含界面状态。
- 上传状态由对应提交功能管理。
- 任务轮询由任务功能管理。
- 阅读正文与来源预览分别管理状态，通过稳定引用合同协作。
- 不为单次使用建立通用抽象。

## 验收要求

### 结构验收

- 八个主要页面或状态均可到达。
- 页面模块与本文件一致。
- 不出现当前后端没有的功能入口。
- 页面标题、主要操作和错误区域顺序稳定。

### 交互验收

- 登录、注册、会话恢复和退出可用。
- 单 PDF 与多 PDF 上传符合后端合同。
- 任务轮询覆盖 queued、处理中、completed、failed 和 cancelled。
- 刷新任务路由可从后端恢复状态。
- 多来源切换和引用定位可用。
- 引用跳转只滚动来源预览。
- 导出使用后端生成的完整材料。

### 浏览器验收

- 在三个规定视口运行真实本地应用。
- 应用外壳无横向溢出。
- 浏览器控制台无意外错误。
- DOM 断言和真实交互是通过标准，截图只作为辅助证据。

## 禁止事项

- 不用前端 `mode` 推断后端 `service_mode`。
- 不用文件名作为来源主键。
- 不在 URL、日志或 `localStorage` 保存长期令牌。
- 不向学生暴露解析器配置。
- 不创建没有后端合同的历史、取消、重试或用户管理界面。
- 不用静态截图替代真实应用验收。
- 不在基础布局中自行加入正式视觉、漫画或冷笑话。
- 不为了统一外观而破坏各工作区真实需要的布局。
